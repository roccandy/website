# Design Studio fonts

Bundled from the Google Fonts repository for consistent browser and server
artwork rendering. Fonts are loaded only when the corresponding Studio family
is used. The server converts lettering into vector outlines for portable SVG,
PNG, PDF and email output; the saved design retains editable text.

- Roboto: https://github.com/google/fonts/tree/main/ofl/roboto
- Roboto Mono: https://github.com/google/fonts/tree/main/ofl/robotomono
- Roboto Slab: https://github.com/google/fonts/tree/main/apache/robotoslab
- Arimo (Arial-compatible glyphs for the site's generic font stack in exports): https://github.com/google/fonts/tree/main/ofl/arimo

Original licence notices are included alongside the font files.
